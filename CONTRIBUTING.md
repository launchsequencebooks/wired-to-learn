# Contributing

This repository mirrors the code printed in *Wired to Learn*, so the listings change only
to fix errors. That keeps the book and the code in step.

**Welcome:**
- Errata reports: a mistake in the book or a program that fails. Use the *Errata report* form.
- Compatibility fixes for new versions of Python, NumPy or PyTorch. Open an issue first and describe the failure.
- Questions and your own experiments: post them in Discussions.

**Not merged:** rewrites of listings, new features or style changes. The printed book cannot change with them.
You are welcome to fork the repository and experiment there.

When you report a problem, please include the chapter and listing number (for example *Listing 31.4*),
your operating system, your Python and PyTorch versions (`python -c "import sys, torch; print(sys.version, torch.__version__)"`)
and the full error message.
